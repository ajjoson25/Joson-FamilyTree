# Joson Family Pedigree

A standalone interactive family pedigree with search, branch expansion, zoom and pan, SVG export, and FamilySearch document links. Research relationships marked provisional require further corroboration.

## Publish on GitHub Pages

1. Create a new repository named joson-family-tree. Initialize it with a README so the main branch exists.
2. Upload index.html into the repository root using Add file > Upload files. Commit the upload to main.
3. Optionally also upload the supplied .nojekyll file. The page needs no build or external assets.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose main and /(root), then Save.
7. Wait for the Pages deployment to finish. Settings > Pages will show the site URL: https://YOUR-USERNAME.github.io/joson-family-tree/

Upload the extracted files, not the ZIP or its enclosing folder. A public repository and Pages site expose the included family names and relationships to visitors.

To update the site, replace index.html in the repository and commit. GitHub Pages will redeploy it.

FamilySearch links may require sign-in or access through a FamilySearch center. The site itself does not require FamilySearch credentials.
